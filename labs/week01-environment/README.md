# Week 01 lab — real Python on your Mac or in Codespaces

Optional. About 25 minutes. The step-by-step instructions, cost and safety
notes live in the app (Labs → *Real Python on your Mac or in Codespaces*).

```bash
python3 labs/week01-environment/check_env.py
```

The script prints a report and a final `ENGACAD-ENV-CHECK …` line. Paste the
output into the lab page to record **self-reported** evidence. EngAcad is a
static site and cannot verify where the script ran, so it never labels this
evidence as verified.

The script needs no network access, credentials or sudo; it writes one
temporary file and deletes it.

Codespaces: stop the codespace when you finish (included usage is limited and
extra usage can be billed).
